# Listing material every store accepts — UNFILLED SKELETON

Kept once because all three stores accept it. A per-store copy would be three places for one
fact to go stale.

- `screenshots/` — **1280x800 is the only size Chrome, Edge and AMO all take.** Chrome also
  accepts 640x400 and Edge 640x480; shipping only 1280x800 keeps one set instead of three.
  24-bit PNG, no alpha, square corners, full bleed. Chrome requires at least one.
- `privacy-policy-url.txt` — all three require a reachable policy for an item handling user data.
- `support-url.txt` — all three ask for it.

The 440x280 and 1400x560 promo tiles are byte-identical between Chrome and Edge and belong here
when they exist. AMO has no equivalent.
