Privacy policy — ⟨TOOL⟩

Last updated ⟨DATE⟩ · applies to ⟨TOOL⟩ version ⟨VERSION⟩ and later

⟨TOOL⟩ does its work on your device. It has no account system, no analytics, no advertising and no server of its own. It makes no network requests of any kind — none to us, and none to anybody else.

That is a claim about the extension's own code, and it is enforced rather than asserted: the extension declares a content security policy that blocks outbound connections at the browser level, and its test suite fails if any shipped file so much as references a network API. The one thing that can carry data off this machine is your browser's own profile sync, which is described below, and which is yours rather than ours.

What ⟨TOOL⟩ never stores

  • Page addresses. Only a scheme and a host are ever recorded — never a path, a query string or a fragment, because those are where names, order numbers, search terms and session tokens live.
  • Credentials, cookies, form contents, or anything you type into a page.
  • Any identifier for you or for this installation. ⟨TOOL⟩ does not generate one, and does not read one.
  • Browsing history. ⟨TOOL⟩ only ever looks at a tab you have pointed it at.

What leaves this device

Nothing that ⟨TOOL⟩ sends. The extension makes no network requests. There is no server to receive anything.

One thing can still travel, and it is worth being precise about it: your browser's own sync. If you are signed in to ⟨BROWSER⟩ with sync switched on, the browser replicates your extension settings to your other computers, through the browser vendor's infrastructure and under the browser vendor's privacy policy — the same way it replicates your bookmarks. That covers the small preferences in the first table row only. It never covers the failure note, the work in progress, or anything ⟨TOOL⟩ has saved for you: those are device-local and stay device-local.

If you would rather nothing travelled at all, turn extension sync off in your browser's sync settings, or use Reset settings on the Options page, which removes ⟨TOOL⟩'s preferences from your synced browser profile.

Getting your data out, and deleting it

All of this is in the extension itself, under Options → Your data. None of it requires contacting us.

  • See it. Everything ⟨TOOL⟩ has saved is listed on that page, with a count.
  • Export it. Export everything writes every saved row to a single JSON file on this device. Nothing is uploaded.
  • Delete one row. Each listed row has its own delete button.
  • Delete all of it. Delete everything empties both the saved rows and the work-in-progress area, after asking you to confirm.
  • Reset your settings. Reset settings puts every preference back to its default and removes them from your synced browser profile.
  • Remove the extension. Uninstalling ⟨TOOL⟩ makes the browser delete its local database and its extension storage. Export first if you want to keep anything.

One caution about local storage, because it is easy to assume otherwise. A browser may delete a site's or an extension's local data on its own if the device runs short of space. ⟨TOOL⟩ asks the browser for durable storage the first time it saves anything, and the Options page tells you plainly which of the two states you are in — “Durable” or “Best effort”. If it says best effort, export a backup.

Reporting a problem

⟨TOOL⟩ has a Report a problem button, and it does not send anything. It builds a small file describing the extension's state — its version, your browser's engine and major version, the counts of what is stored, and the reason code for the last failure — shows you the entire contents before it is written, and then saves it to your device. What you do with that file is entirely your choice. The report is assembled from a fixed list of fields that contains no page addresses, no page text and nothing ⟨TOOL⟩ has saved for you; free-text settings are reported as “(text)” rather than by value.

Limited Use disclosure

⟨TOOL⟩'s use of information received from Google APIs, and any information obtained through the extension, adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Specifically: ⟨TOOL⟩ transfers no user data anywhere; uses data only to provide the single user-facing feature described in its store listing; does not use user data for advertising, for building profiles, or for training any model; does not sell user data; and permits no human to read user data — there is nowhere for a human to read it from, because nothing is transmitted.

Children

⟨TOOL⟩ is not directed at children, collects no personal information from anyone, and transmits nothing.

Changes to this policy

If ⟨TOOL⟩ ever begins handling data differently, this page is updated and its date at the top changes before the new version ships. A change that widened what is stored, or that introduced any transmission, would also be described in the extension's release notes and in its Web Store listing.
