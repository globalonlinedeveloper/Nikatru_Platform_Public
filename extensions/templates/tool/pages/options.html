Your data

Nothing is stored on this device.

    Export everything Saves every stored row to one JSON file on this device. Nothing is uploaded.
    Delete everything Removes every stored row from this device. Settings are kept.
    Reset settings Puts every setting on this page back to its default and removes them from your synced browser profile. Stored rows are kept.

    Site access

    Access to every site Only needed for the features that work on pages you have not clicked the toolbar button on. You can take it back at any time, here.

    Report a problem

    Prepare a problem report Builds a small file describing this extension’s state. You see exactly what is in it before it is saved, and nothing is sent anywhere.
